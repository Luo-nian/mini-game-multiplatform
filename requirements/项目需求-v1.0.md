# v1.0 需求 · 小游戏变现路线选定

> 提出人：Boss｜整理：王秘书｜日期：2026-09-22
> 阶段：**路线选型（玩法暂不讨论）**｜状态：待拍板

---

## 0. 一页结论

1. **能零成本做**。微信小游戏个人主体的注册、备案、上传、广告接入**全免费**；纯单机玩法**不需要买服务器和域名**。
2. **零成本 ≠ 能赚钱**。行业真实数据：微信小游戏**前 5% 的产品拿走 80% 以上利润**，个人自研纯广告游戏的常态是**日入 40~45 元**。
3. **你说的「盈利概率 ≥75%」只有在一种定义下才成立**：**盈利 = 总收入 > 0**（因为成本是 0，进 1 分钱就是盈利）。平台会送冷启动流量，这个定义下概率能有 80%。
   **如果你要的是「月入过千」，75% 是伪命题——任何方案都做不到**，行业支持的概率只有 5~10%。这句话我必须先讲清楚，否则后面全是空谈。
4. **推荐路线：一套代码，三端分发**——① 233乐园（最快见钱、零资质）② 微信小游戏（国内主战场）③ CrazyGames 等海外 H5（零资质、审核 1~2 天）。抖音视资格实测结果决定是否加入。
5. **200 元最优花法**：只在「抖音必须要软著」被证实的前提下，花 **50~100 元**办电子版权认证把上线周期从 3 个月压到 7 天；其余**一分不花**。买量、买素材、买源码——都别花。

## 1. 平台准入对照（个人主体 / 无营业执照）

| 平台 | 个人能做吗 | 硬性资质 | 上线前置耗时 | 变现门槛 | 成本 |
|---|---|---|---|---|---|
| **微信小游戏** | ✅ 可以（注册选「个人」+ 一级类目「游戏」） | 身份证 + 小程序备案；**休闲益智类纯广告一般不需版号**；软著多为选填 | 备案 5~20 工作日（**瓶颈**） | 流量主：累计 UV > **500** | 0 元 |
| **抖音小游戏** | ⚠️ **口径冲突，必须实测** | 多方实测口径：**软著必填** | 审核 1~7 工作日，可先上线后补备案 | **无 UV 门槛，上线前即可开通流量主** | 0~100 元 |
| **233乐园**（UGC） | ✅ 可以，仅实名 | <50MB 非商业 UGC **免软著**；开广告分成才要软著（平台可代申请，最快 7 天） | 快 | 广告分成 | 0 元 |
| **CrazyGames**（海外） | ✅ 开放提交 | **无** | QA 反馈 1~2 天 | 基础发布即上线；接 SDK 后开始分成 | 0 元 |
| **Poki**（海外） | ✅ 但要过审 | **无** | 精选制人工审核 + 两轮实测（3~5 天） | 过 Player Fit Test 才有收入 | 0 元 |
| 快手 / QQ 小游戏 | ❓ 需另测 | 疑似偏企业 | — | — | — |

**关于抖音的矛盾必须说清楚**：抖音开放平台官方 FAQ（2026-05 更新）原文是「个人身份目前仅支持创建**小玩法**类型；小程序、移动应用、网站应用仅支持企业主体」。但大量个人开发者实测文章称「个人可正规做抖音小游戏，仅需身份证实名，软著必填」。两者标准不一，**结论只能靠注册时实测**（30 分钟内可知，见 §7 第 0 步）。

**微信个人主体的硬限制**（避免白做）：
- 一级类目只能选「游戏」，**注册后不可改**；二级类目个人**不支持**文化互动 / 角色 / 牌类，**只能选休闲益智等轻休闲** → 棋牌、捕鱼类个人直接出局。
- 个人**不能微信认证**（省下 300 元/年），代价是**不能开通微信支付 → 做不了内购**，只能纯广告（IAA）。
- 个人主体**无法变更为企业**，选错只能注销重注册。
- 备案期间**不允许改名改主体** → 名称要一次定死。

### 2.1 一分钱不花的路径（完全可行）

| 环节 | 费用 | 说明 |
|---|---|---|
| 微信小游戏账号注册 | 0 | 个人主体免认证费 |
| 小程序备案 | 0 | 微信后台自助，需人脸核验，5~20 工作日 |
| 小游戏备案（游戏内容） | 0 | 平台初审 1~2 工作日 + 主管部门 10~20 工作日 |
| 域名 ICP 备案 | **不需要** | **仅当自建后端 / 自有域名时才要**。纯单机游戏只用微信原生接口 → 跳过 |
| 服务器 | **不需要** | 数据存本地 / 微信自带能力，零后端 |
| 软著（普通申请） | 0 | 中国版权保护中心自办，**30~60 工作日** |
| 开发 | 0 | 自己写 + AI 辅助；美术用几何/纯色/emoji，不买素材 |
| 233乐园上传（<50MB 非商业 UGC） | 0 | 仅实名认证 |
| CrazyGames 提交 | 0 | 免费，无独占要求 |

> ⚠️ **别被「启动金」误导**：微信新游可领 1000 元启动金（上线 30 天内），但那是**信用金，先花后还**——后期会从你的广告分成里扣。不是白送的钱。

### 2.2 200 元怎么花才值（仅在概率达标时才动）

| 用途 | 金额 | 值不值 |
|---|---|---|
| 电子版权认证（软著加急） | 50~100 元 | ⭐ **唯一值得花的一项**。把上线周期从 3~4 个月压到 3~7 天，且抖音/部分平台认可 |
| 域名 | 30~60 元/年 | 仅当需要自建排行榜或做 SEO 站时。第一版用不上 |
| 微信企业认证 300 元/年 | — | ❌ 个人用不上，且超预算 |
| 买小游戏源码 | 几十~几百 | ❌ 侵权风险 + 同质化，审核易被拒 |
| 买美术素材包 | — | ❌ 第一版用几何风格即可 |
| 买量投放 | 200 元 | ❌ 200 元买量连测试数据都跑不出来，直接打水漂 |

## 3. 收益现实：把你听到的数字分开看

**先说残酷面（这些是真实统计，不是唱衰）**

- 网页游戏收入极度头部集中：约 **80% 的游戏月收入 $0~50**，15% 在 $50~500，**只有约 4% 到 $500~2000**，<1% 到 $2000~10000，<0.2% 超过 $10000（itch.io 收入分层统计）。**大多数游戏终身收入不到 $100**。
- 微信小游戏生态十万款以上产品，**营收前 5% 拿走 80% 以上利润**，排在后面的月流水几百到几千。
- 平台激励政策（首发新游 5000 万免分成、2000 万激励金）**门槛是月流水先破 10 万**，和新人无关。
- 微信种子计划（官方冷启扶持，一游仅一次、上线 90 天内）**实测效果：只持续 3 天、每天新增几十人**。

**再说可行面**

- 真实案例：个人自研纯广告微信小游戏，**日广告收益稳定 44 元上下**（后台截图，无付费推广）→ 大约 **月 1300 元**，且是"上线后躺着来"的被动收入。
- 233乐园口径：个人开发者广告分成**平均月入 3200 元**（第三方行业报告），头部月分成 10 万+；平台 2025 年给创作者分成超 3 亿元。
- 抖音新游冷启：预估 3 天给 1 万曝光 UV（实测转化约 20%）。
- 海外网页游戏：多款平淡作品累计 45 万次播放 → 约 €557（约 **€1.2/千次播放**）；做得好的一款可以到月入数千元。

**结论**：这条路的钱是"**几十块起步、慢慢滚**"的形态。想快速回本，只有一条路——**把量做起来**。而量 = 平台给的自然流量（少）+ 你自己产的内容带来的流量（可控）。

## 4. 盈利概率（我的估算，非承诺）

以「做完 1 款、上 2 个平台、每月投入 10~20 小时、自己产内容」为前提：

| 目标 | 估算概率 | 依据 |
|---|---|---|
| 上线并拿到**第一笔广告收入（>0 元）** | **80% 左右** | 平台冷启流量 + 广告接入门槛低（微信 UV>500 / 抖音无门槛） |
| 月收入 **≥ 100 元** | 30~40% | 需要产品留存过关 + 有一点自然量 |
| 月收入 **≥ 500 元** | 10~15% | 需要过审 + 留存 + 内容引流三者都成立 |
| 月收入 **≥ 2000 元** | 3~5% | 接近行业"前 5%"门槛 |
| **「至少 1 款月入 ≥ 500 元」**（做 3 款 + 三端分发） | **30~40%**（组合后提升） | 多款叠加对冲单款失败 |

**这张表的意思是**：你说的 75% 只有在第一行（收入 > 0）成立。第二行开始，没有任何诚实的人能给你 75%。**所以真正的决策不是"选哪个方案"，而是"把盈利线定在哪一档"** —— 这决定我们要不要花那 200 元，以及要不要投入 3 个月。

---

## 5. 75% 成立的三个必要条件

要让我敢说"这事大概率不亏"，必须三条同时成立：

1. **判定线定在「总收入 > 0」**——成本为 0，任何收入即盈利。
2. **多平台分发**——单平台的自然量不足以兜底；三端同时上，任一端被限流不影响全局。
3. **你本人愿意持续产内容引流**——这是唯一零成本的获客手段，也是把 30% 抬向 75% 的关键变量。不做内容 = 只能吃平台残羹，概率腰斩。

## 6. 推荐路线（一套代码，三端覆盖）

**技术选型**：Cocos Creator（TS）或原生 Canvas/JS（微信小游戏原生 + H5 直接跑）。
理由：一次开发可导出「微信小游戏 + 抖音小游戏 + Web Mobile」，正好满足你要的"覆盖"。
**第一版必须满足的 5 条硬约束**（不满足就赚不到钱）：
1. 零后端（纯单机 / 本地存档）
2. 零外购素材（几何 + 纯色 + 系统字体）
3. 单局 ≤ 60 秒、3 秒上手（超休闲）
4. 广告只放在**用户主动触发**的位置（复活 / 双倍 / 提示），不放强制弹窗
5. 题材合规：避开棋牌、捕鱼、抽奖概率、他人 IP

**分发优先级**：

| 顺位 | 平台 | 为什么排这个位 |
|---|---|---|
| ① | **233乐园** | 零资质、免软著（<50MB）、**最快拿到第一笔真实收入**，用来验证玩法 |
| ② | **CrazyGames** | 零资质、开放提交、1~2 天反馈、无独占要求，可同时上别家 |
| ③ | **微信小游戏** | 国内主战场、代码可直接复用；但备案 5~20 工作日是瓶颈，**必须第一天就启动** |
| ④ | 抖音小游戏 | 视 §7 第 0 步实测结果；能上就上（短视频自然流量是它最大的红利） |
| ⑤ | Poki | ⚠️ 要求**网页独占**（不能与其他网页平台同发），放到最后作为进阶 |

**时间线**：

- **第 0 周（本周）**：注册微信小游戏个人主体（名称一次定死）→ **立刻提交备案**（不占用你时间，后台跑）→ 注册抖音开发者并**实测个人能否创建小游戏** → 233乐园实名 → 视抖音结果决定是否启动软著/电子版权认证
- **第 1~2 周**：开发第一版（含 1 个完整关卡即可提审，不用做全量）
- **第 3 周**：233乐园 + CrazyGames 上线（快）；微信备案通过后提审
- **第 4~6 周**：申请微信种子计划 / 抖音新游冷启（**上线即申请，都只有一次机会**）；开始产出短视频 / 图文引流
- **第 7~12 周**：看数据。留存达标就迭代，不达标就快速做第 2 款（**多款对冲是提升概率的核心手段**）

### 10.1 ⚠️ 关键修正：233 不是"上传 APK"的开放平台

调研 233 的创作工具后必须更正第 6 节的表述。233 有**三条创作工具线**，作品形态由工具决定：

| 工具线 | 端 | 面向谁 | 特点 |
|---|---|---|---|
| **口袋方舟** | PC | 半专业开发者 | 创作者留存极深、有稳定收入、**允许把作品单独打包发布到外部** |
| **造物岛** | 移动 | 普通玩家 | >90% 创作者原本零基础，轻量创作 |
| **233工坊** | 多端 | AI 驱动 | 文字描述直接生成游戏，一键发布；需先申请创作者资格，生成消耗积分 |

**⚠️ 必须知道的取舍**：用 233 自家工具做出来的游戏**锁定在 233 生态内**，无法一键搬到微信 / 抖音 / 海外平台；反过来，自研代码做的微信小游戏也进不了 233 的 UGC 推荐池。
→ **「先用 233 起步」和「一套代码多端覆盖」是两条不同的路，不是先后关系。**

### 10.2 为什么 233 反而最适合"不做内容"

- 233 官方明确：**推荐机制不以商业化或广告投放为前提，基于内容质量本身分发**，并逐步提高「种子用户留存、持续更新」的权重 → 平台自带自然流量，不吃站外内容
- 233工坊正在办「脑洞成真」AI 游戏创作大赛等活动，提供**现金激励、乐币、会员、积分** → **参加平台活动拿奖金，是比广告分成更快的第一笔收入，同样不需要产内容**
- 核心用户 72% 是 14~22 岁 Z 世代，ACG / 解压 / 答题 / 模拟经营接受度最高
- 审核是「合规审查 + 人工体验（看游戏性/完整度/亮点）」双重 → 质量导向，对新人不算坏消息

### 10.3 修正后的概率

- 233 路线下「拿到第一笔收入」仍约 **80%**（平台自带推荐流 + 活动奖金兜底）
